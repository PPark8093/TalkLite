TalkLite - 초간단 1:1 PC 음성통화
================================

구조
----
- 전화를 거는 사람이 서버가 됩니다.
- 서버 프로그램은 TCP 39876 포트를 열고 친구의 연결을 기다립니다.
- 친구는 서버 PC의 IP 주소로 연결합니다.
- 중앙 음성 서버 없이 두 PC 사이에서 오디오를 직접 전달합니다.

중요: 인터넷에서 사용할 때
---------------------------
1. 서버(전화 거는 사람) PC에서 TalkLite.exe를 실행합니다.
2. Windows 방화벽이 허용을 묻는다면 사설 네트워크에서 허용합니다.
3. 공유기 뒤에 있다면 TCP 39876 포트를 서버 PC로 포트포워딩해야 합니다.
4. 서버 PC의 공인 IP를 친구에게 알려줍니다.
5. 친구는 '친구에게 받기'를 선택하고 그 IP를 입력한 뒤 연결합니다.

같은 Wi-Fi/LAN에서는
--------------------
서버 PC의 사설 IP(예: 192.168.0.12)를 친구가 입력하면 됩니다.

주의
----
- 양쪽 PC 모두 마이크와 스피커가 있어야 합니다.
- 스피커 대신 헤드셋을 권장합니다. 스피커를 사용하면 자신의 목소리가 다시 들릴 수 있습니다.
- 현재 버전은 1:1 음성통화만 지원하며 통화 녹음, 계정, 채팅, 영상은 없습니다.
- 인터넷 연결은 P2P에 가깝지만 NAT/공유기 환경에 따라 포트포워딩이 필요합니다.

Windows EXE 만들기
------------------
Windows PC에서 이 폴더를 연 다음 build_windows.bat를 실행합니다.
완성 파일: dist\TalkLite.exe

개발 실행
----------
py -m pip install -r requirements.txt
py talklite.py
